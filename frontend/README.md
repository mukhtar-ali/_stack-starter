# Frontend

This project was bootstrapped manually to mirror the output of `create-next-app` with TypeScript, ESLint, and Tailwind CSS enabled. It also includes Storybook, Jest with Testing Library, and TanStack Query integration.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Run Storybook:

```bash
npm run storybook
```

Run tests:

```bash
npm test
```

Build for production:

```bash
npm run build
```
